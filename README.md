# Программа в рамках курса обучения SkyPro

## Описание:
Проект банковского приложения для получения информации по операциям по счетам и банковским картам.

## Установка:
1. Клонируйте репозиторий:
```

```
2. Установите зависимости:
pip install -r requirements.txt

## Использование:
Проект в стадии разработки.
На данный момент в проекте созданы следующие функции:
1. Функция вывода номера карты, в котором часть числовых значений принимают символ "*"
2. Функция вывода номера счёта, в котором часть числовых значений принимают символ "*"
3. Функция, маскирующая номер счёта или карты
4. Функция преобразования формата даты "2024-03-11T02:26:18.671407" в формат "ДД.ММ.ГГГГ"
5. Функция сортировки операций по статусу, по умолчании статус операции EXECUTED
6. Функция сортировки данных по дате, по умолчанию сортировка в порядке убывания
7. Функция-генератор фильтрации операций по типу валюты
8. Генератор описания операций
9. Генератор номеров банковских карт

## Тестирование
Все текущие функции протестированы фреймворком Pytest, коэффициент покрытия составляет 95%.
